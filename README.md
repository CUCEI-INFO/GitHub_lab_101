# GitHub_lab_101
Seminario de integración y desarrollo.

## Problema y objetivo:
El phishing representa un riesgo para los usuarios de internet que puede ocasionar problemas económicos, de seguridad y privacidad.

Como objetivo se tiene la creación de una extensión de navegador que reconozca posibles intentos de phishing que estén sucediendo con al menos un 95% de precisión a la hora de detectar amenazas.
