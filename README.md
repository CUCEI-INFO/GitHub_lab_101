# GitHub_lab_101
Seminario de integración y desarrollo.

## Problema y objetivo:
El phishing representa una amenaza para la seguridad y privacidad de los usuarios de internet, ya que utiliza enlaces y sitios web fraudulentos para engañarlos y obtener información confidencial. La identificación de estas amenazas puede resultar difícil para los usuarios, por lo que se requiere una herramienta que les ayude a reconocer enlaces potencialmente maliciosos antes de acceder a ellos.

Crear una extensión de navegador web que reconozca posibles intentos de phishing con al menos un 95% de precisión en la detección de amenazas.
